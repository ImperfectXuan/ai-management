# Project: AI Workspace

This repository is the **AI Workspace infrastructure project** — a shared
layer that provides rules, conventions, skills, and project memory to
AI Coding tools including Claude Code.

## For Claude Code Working in This Repo

### Navigation

- Canonical rules: `.ai-workspace/rules/`
- Tool adapters: `.ai-workspace/adapters/`
- Claude Code adapter: `.ai-workspace/adapters/claude/`
- Documentation: `docs/`

### Rules for Contributing

1. Never edit root-level tool stubs directly for content changes.
2. Edit canonical rules in `.ai-workspace/rules/` for rule changes.
3. To add support for a new AI Coding tool, create a directory under
   `.ai-workspace/adapters/` and follow the existing pattern.
4. Run `.ai-workspace/scripts/sync.sh` after rule changes.
5. Run `.ai-workspace/scripts/validate.sh` before committing.

### Code Conventions

- Documentation in Markdown.
- Scripts are POSIX-compatible shell.
- Directory names in kebab-case.
- Every directory contains a `.gitkeep` until populated.
- Frontmatter in `.md` files uses YAML.

### Architecture Constraints

- The `rules/` module must remain tool-agnostic.
- Adapter files must be under 50 lines.
- Sync scripts must be deterministic.

## For Claude Code Working in Projects That Use AI Workspace

When a project includes `.ai-workspace/`:

1. Read `.ai-workspace/rules/00-core.md` first.
2. Load domain-specific rules from `.ai-workspace/rules/domains/` as relevant.
3. Reference `.ai-workspace/memory/` for project context and decisions.
4. Canonical rules are authoritative; derived files may lag.
