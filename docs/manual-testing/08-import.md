# 08 · 反向导入（import）

> **测试对象**：`aiws import mcp|skills|rules` 反向收编工具里已存在的配置，含 `--dry-run` 预览、`-y` 跳过确认、去重与备份。
> **前置**：[07-sync.md](07-sync.md)（理解生成文件与「managed」标记）。
> **写文件**：实际导入（非 `--dry-run`）会写规范层。建议临时仓库。

---

## 1. 目标

反向导入是正向 sync 的逆过程：把散落在各工具里的存量配置收编进 `.ai-workspace/`。本域验证：

1. `--dry-run` 只预览不写。
2. `import mcp/skills/rules` 分类（新增 / 已管理 / 冲突）正确。
3. 实际导入能落地到规范层并登记 mapping。

---

## 2. 前置

```bash
cd /Users/xuanyi/Documents/AI-management
AIWS=./.ai-workspace/scripts/aiws
```

## 3. `import mcp`（预览）

### 步骤 3.1 — 预览

```bash
$AIWS import mcp --dry-run
```

**预期**：`=== MCP Import (DRY RUN) ===`，扫描各工具 MCP 配置，输出 `[DRY-RUN] Would add: <name> (scope: <scope>)` 或「已管理跳过」，结尾 `Dry run complete.`

**判定**：✅ 预览不报错、不写 `mcp.json`（用 `git status` 确认无改动）。

### 步骤 3.2 — 从指定工具预览

```bash
$AIWS import mcp --from codex --dry-run
```

**预期**：只扫描 Codex（`.codex/config.toml`，走 TOML 解析），列出可导入项。
**判定**：✅ 能解析 Codex 的 TOML 格式。

$AIWS import skills --dry-run

**预期**：`=== Skills Import (DRY RUN) ===`，汇总三类：

## 6. 实际导入（临时仓库，以 rules 为例）

`import rules` 最直观：把工具目录里**手写、未纳管**的规则反向收编进 `rules/domains/`。

### 步骤 6.1 — 造一条手写规则

```bash
TMP=$(mktemp -d /tmp/aiws-import.XXXXXX)
cd "$TMP" && git init -q
cp -R /Users/xuanyi/Documents/AI-management/.ai-workspace "$TMP/"
AIWS_TMP=./.ai-workspace/scripts/aiws

mkdir -p .cursor/rules
cat > .cursor/rules/custom-rule.mdc <<'EOF'
---
id: custom-rule
title: 手写自定义规则
scope: all
---

# 手写自定义规则

这是一条手写、尚未纳管到 .ai-workspace 的规则，用于测试反向导入。
EOF
```

> 注意：这条文件**没有** `Generated by AI Workspace` 标记，import 才会把它当「未纳管」处理。

### 步骤 6.2 — 预览确认

```bash
$AIWS_TMP import rules --from cursor --dry-run
```

**预期**：汇总里 `New (will import): 1`，并列出该规则。
**判定**：✅ 识别为新增。

### 步骤 6.3 — 实际导入（`-y` 跳过确认）

```bash
$AIWS_TMP import rules --from cursor -y
```

**预期**：`Rules import complete: 1 imported, 0 failed.` + `Run 'aiws sync' to propagate imported rules to all tools.`

```bash
ls .ai-workspace/rules/domains/custom-rule.md
```

**预期**：`custom-rule.md` 已出现在 `rules/domains/`。
**判定**：✅ 反向导入落地。

### 步骤 6.4 — 同步后新规则生效

```bash
$AIWS_TMP sync --only rules >/dev/null
ls .cursor/rules/custom-rule.mdc
```

**预期**：现在 `.cursor/rules/custom-rule.mdc` 已被 sync 重新生成（带 managed 标记）。
**判定**：✅ 导入 → 登记 mapping → sync 生成，形成闭环。

### 步骤 6.5 — 收尾

```bash
cd / && rm -rf "$TMP"
```

---

## 7. 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 预览显示 `Nothing to import` | 工具里没有「未纳管」配置 | 属正常，先手工造一条再测 |
| 导入提示 `[y/N]` 等待输入 | 未加 `-y` | 用 `-y` 跳过，或手动确认 |
| `import rules` 后 sync 丢弃了规则 | 目标工具缺 `mapping.yaml` | 看告警，先 `aiws setup` 补齐映射 |
