# 001 · 实施任务拆分

依据：[spec.md](spec.md)。逐步交接：[coding-prompts.md](coding-prompts.md)。实际状态仅见 [PROGRESS](../../PROGRESS.md)。

## 1. 执行顺序

按 TASK-001-01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 顺序推进。每一步只交付自身范围；完成条件满足后再进入下一步。任务是逻辑交付单元，过大时可在同一任务下拆小 PR，不删减验收。

先让非 AI 的扫描、审核和复用逻辑可验证，再将 AI 建议接入候选契约。现有产品方向不需要反复确认；工程缺口先核实再处理。

## 3. 各任务完成条件

### TASK-001-01 · 技术设计

只做调查和设计，不实现功能。交付 `design.md`，包含 spec §6 六项、字段级数据契约、CLI / IPC 契约、目录 / Git 边界、凭据方案、事务及恢复状态机、适配器能力矩阵。

核实 existing import 的预览副作用、规则 global 支持、Skill 软链接行为、Desktop 单文件规则同步、MCP 文件保留、初始化顺序等实际差距。不得把“现有函数存在”当作满足规格。

完成条件：所有 AC 均能对应设计；兼容与新增运行时约束明确；技术问题有结论或真实阻塞原因；tasks 与方案一致。没有执行功能验收，不能标为通过。

### TASK-001-02 · 多来源扫描

实现选定来源、工具适配器、手动来源、三类资产及来源记录；CLI 输出版本化 JSON / 人类可读预览，提供进度与取消。敏感字段在形成持久候选前分离，后续任务不得再清理已泄露的快照。扫描预览保证零写入（含不创建空配置文件）；不改变现有 `import` 的 dry-run 行为，新扫描独立实现。

完成条件：四工具项目 / 全局能力矩阵夹具、单应用安装、未初始化目录、断链 / 外部链接、生成副本、坏格式、不可读来源测试通过；扫描前后来源文件内容一致；预览不写入任何文件；所有错误可定位。

### TASK-001-03 · 比较与增量

实现完整内容指纹、规则行为元数据、Skill 目录清单、MCP 行为字段与安全凭据身份；来源关系、忽略与暂缓记录。总库既有内容能参与比较。

完成条件：跨名相同、同名不同、Skill 脚本改变、规则条件改变、MCP 参数顺序 / 账号差异、重复扫描及忽略后变化测试通过；来源删除不删总库。

### TASK-001-04 · 审核及入库引擎

实现六种动作、最终计划预览、目标版本复核、稳定资产 ID、历史版本、mapping 登记、批次幂等、并发检测、预备写入、失败恢复及受约束回退。CLI 可消费人工审核计划，不能由扫描直接批准写入。

完成条件：六动作、未处理冲突、取消、计划过期、重试、并发、阶段故障注入、回退后续修改保护测试通过。新版本内容及元数据一致；现有 import 兼容。

### TASK-001-05 · Desktop 人工闭环

接入共享引擎，提供总库选择、来源选择、扫描结果与来源详情、差异预览、动作编辑、批量操作、最终确认、入库结果。无模型时可完成流程。Desktop 单文件规则同步通过桥接 CLI `generate_tool_file` 实现，不另行用 TS 重写规则拼接逻辑。

完成条件：组件 / IPC 集成验证覆盖选择、冲突确认、取消、过期计划及错误；实际 Desktop 完成一次非 AI 收编，来源不变，总库只包含确认动作。

### TASK-001-06 · AI 调用边界

实现服务地址、模型名与凭据引用配置；发送内容预览确认；候选 / 总库比较范围；结构化建议校验、原文锚点校验、批次进度、超时 / 取消 / 重试。

完成条件：模拟模型边界测试覆盖未授权发送、范围扩展、敏感值过滤、非法来源引用、无效响应、超时 / 部分失败；请求与日志不泄露夹具密钥。不用真实付费调用作为自动测试前置。

### TASK-001-07 · AI 建议审核

实现拆分与分类预览、原文对照、候选间及总库相似关系、合并理由、矛盾提示、人工编辑、拒绝 / 暂缓、重试保留编辑。AI 建议转换成同一审核计划，不另建直接写入通道。

完成条件：整文件拆分 / 漏段可见、同义不同名、互相矛盾、AI 重试保留编辑、只入库确认结果测试通过；完成带模拟结果的 Desktop 演示。

### TASK-001-08 · 复制及更新引擎

实现选定资产 / 项目 / 工具的复制计划、MCP 凭据及本机依赖绑定、独立副本、复制基准、三方比较、目标初始化预览与受保护同步。全局来源不默认分发全局。同步原生内容保护细化为三项：MCP 合并写入保留未选 server、规则同步前影响预览、Skills 非 managed 目标备份后处理。

完成条件：Rules / Skill / MCP 复制及更新夹具覆盖三方比较所有结果；独立副本、工具选择、原生内容保护、mapping、绑定后基准、工具漂移、未初始化目标、复制和同步分阶段失败 / 重试测试通过。

### TASK-001-09 · Desktop 复用闭环

接入资产选择、目标与工具选择、初始化与存量提示、依赖绑定、复制及同步最终预览、逐阶段结果、主动检查更新和人工冲突处理。

完成条件：完成两个目标项目的人工旅程，验证未选择目标不变、项目定制被保留；组件 / IPC 覆盖失败和取消。UI 不把复制成功显示为同步成功。

### TASK-001-10 · 验收与收尾

逐 AC 执行真实集成验证并记录 commit / 环境 / 命令 / 结果。覆盖既有 import / sync / validate、Desktop 与 TUI 回归；具体命令依据当前 package 和测试入口，不沿用过时计划。

补充个人操作手册、CLI / Desktop 使用说明、人工测试、总体 SPEC 边界、能力盘点、追踪、PROGRESS 与 CHANGELOG。部分内容无法验证时记录未执行与原因，不倒填通过。

完成条件：所有适用 AC 有证据；失败全部解决，未执行项及产品影响明确报告；文档与最终实现一致。只有满足这些条件才可声明功能完成。
