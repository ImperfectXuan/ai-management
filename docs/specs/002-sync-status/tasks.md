## 2. 完成条件

### TASK-002-01 · 状态契约与本机 Store

新增 `shared/sync-status.ts`、`core/sync-status-store.ts`，包含明确的状态字面量、完整单元键、带 keyId 的 lastSuccess/lastAttempt、Skills 有效输出指纹和 needsResync。

完成条件：通过真实临时文件验证重启读取、原子写失败保留旧数据、坏 JSON/未知 schema 显式失败、running 恢复 interrupted、旧 lastSyncAt 不补成功记录；状态归约验证同版本失败也必须 pending，keyId 缺失或不匹配优先为 unknown。状态内容不含敏感正文；路径身份测试包括符号链接别名和普通子目录。

### TASK-002-02 · 输入与指纹

实现 design §3 和输入描述接口，使用真实 CLI 的工具/模块适用筛选。覆盖所有有效输入、删除与实际生成器依赖；派生 keyId，独立生成不包含工具身份的 Skills 有效输出计划指纹；查询不创建密钥、不解密 vault。

完成条件：夹具验证正文/required/context/附属脚本/MCP 本地覆盖/权限/加密 vault 变更；无关日志与不适用规则不影响；对象键序稳定、数组顺序敏感；软链接边界、坏配置、文件读取中变化、密钥丢失/格式错误/原位替换可诊断；同 keyId 的来源变化与换 key 可区分，运行中换 key 阻止成功提交。所有凭据均使用合成值，不输出真实配置。

### TASK-002-03 · CLI 单元回执

新增回执库及可选参数；在规则、MCP、Skills 的实际完成和跳过点填写 applied/skipped/failed，只有 applied 带 completedAt。

完成条件：无报告参数时现有命令兼容；有报告时覆盖缺 mapping、缺 jq、无内容、模块禁用、不支持 scope、凭据未解决和部分失败；报告不完整或不匹配时 Desktop 拒绝记成功。首条规则与空库、最后一个 server/Skill 删除均有真实引擎测试，不假定跳过等于清理。

### TASK-002-04 · 统一执行服务

组合既有 syncRun，串行执行单元；先持久化尝试，再执行，再校验回执与结束指纹，最后提交单元成功。outputKeys 决定锁和跨记录失效；按 design §2.3 保存等价候选快照，先临时失效，在稳定成功后与本单元成功记录一并原子恢复仍可信的候选。

完成条件：真实临时库与两个项目验证单元独立成功；一个失败不污染无输出重叠的其他单元；取消终止进程组，未启动单元不改变；运行期间来源变化阻止提交；成功前后模拟记录写失败与进程中断可恢复；全局路径和 Codex/Claude Skills 别名不会并发覆盖。同库共享计划完整同步、重复同步后两个工具均 current；失败/取消/中断/换 key 时重叠记录保持 pending 或 unknown，不同库/不同计划/部分重叠仍失效，未记录及先前失效的工具不得被自动记成功；候选恢复保留原时间和执行结果。

### TASK-002-05 · 全部写入入口接线

SyncRun、SyncAll、托盘、SkillsLink/Unlink 统一进入 service；main 启用单实例约束。来源修改、入库/回退触发失效通知，但最终判断读取真实文件。

完成条件：没有绕过 service 的 Desktop 同步与单项 Skill 写入路径；单项链接不更新模块 lastSuccess，卸载使 needsResync；global 不污染 project。保留现有备份、错误反馈与成功时间兼容行为，删除以 lastSyncAt 直接推导全量完成的代码。

### TASK-002-06 · 界面与状态查询

新增 SyncStatusGet/SyncStatusChanged，renderer 接入聚合与单元状态、原因、历史成功时间和最近检查时间，完整身份过滤事件并丢弃过期响应。

完成条件：重启、切页、换库/项目/工具不丢状态；外部编辑在刷新/激活时被识别；读取失败明确展示 unknown；没有项目时不显示 project current；“来源版本已同步”和“目标 diff 一致”独立展示。实际 UI 不展示实现字段、哈希、数据库结构等工程细节。

### TASK-002-07 · 集成与交付

执行 verification 中对应 AC 的真实夹具与原生 Desktop 步骤，重点覆盖共享状态收敛与密钥替换；补齐版本、日期、环境、结果与遗留问题。更新 Desktop 使用说明、验收指南、能力盘点、追踪矩阵、PROGRESS；功能实际交付时更新 CHANGELOG，不在设计阶段提前发布功能完成声明。

完成条件：AC-002-01～18 均有结果和明确覆盖端；未执行的 GUI、打包或平台检查保持未执行。检查打包后 CLI 回执库已被 extraResources 收录，不能仅凭源码构建通过宣称安装包验收通过。
